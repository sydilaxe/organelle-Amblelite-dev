Controllers

Write the Amble Lite set to your KORG with KORG KONTROL Editor first (docs/controllers in the repository: AmbleLite.nktrl_st_set, AmbleLite.nanokey_st_set). Then change what any control does here, copy user.txt into the AmbleLite folder's controllers folder, and choose Profil: user on the MIDI page. user.txt holds both controllers.
